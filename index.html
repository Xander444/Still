How Still works

Still uses written conversation rules, word patterns, and notes from this chat. It can miss context, sarcasm, or the meaning of a sentence. Correct it any time. It cannot diagnose, provide treatment, or contact help for you.

There are no accounts, analytics, remote fonts, language models, or API keys. A hosting provider may log page visits; Still's code does not send your messages anywhere.
